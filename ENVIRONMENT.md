# Environment record

## Environment of the published runs

All reported runs were executed on a single machine; per-run records
(`results/*.manifest.json`) carry the run-time snapshot (commit, seeds,
budgets, solver paths, CPU) for the locked tests.

- OS: Linux (kernel 7.0.0-42-generic), x86_64
- CPU: Intel(R) Core(TM) Ultra 7 155U (12 cores), 30 GB RAM
- Python 3.14.4 with the pinned packages in `requirements.txt`
- Gurobi 13.0 (gurobipy 13.0.2) — commercial licence required
- IBM ILOG CP Optimizer 22.2 via docplex 2.32.264 — commercial licence required
- Julia 1.7.0, single thread (`-t 1`), depot at a local `JULIA_DEPOT_PATH`;
  this matches the Julia version of the original Rolim et al. capsule
  (`rolim_capsule/environment/`). On another machine, point the harnesses
  at your installation with the `HLBB_JULIA` and `JULIA_DEPOT_PATH`
  environment variables (defaults = the recorded run machine's paths; see
  MANIFEST's documented-exception note)
- LKH-3.0.7 (Helsgaun): NOT bundled. Build from the author's source
  distribution (http://webhotel4.ruc.dk/~keld/research/LKH-3/): unpack
  `LKH-3.0.7.tgz`, run `make`, and place the tree as `./LKH-3.0.7/` next to
  the Python code (the binary is invoked as `./LKH ATSP/<name>.par` inside
  that directory). Use of LKH is subject to the author's own terms
  (free for research purposes); this repository grants no rights over LKH,
  Gurobi or CP Optimizer. The SHA-256 of the official source archive is
  recorded at release time in MANIFEST.md.

What is KNOWN versus MEASURED, kept apart deliberately:

- Measured on 2026-11-10 on the run machine: the version pins above and in
  `requirements.txt`.
- Recorded AT RUN TIME by the locked runners (`results/*.manifest.json`):
  commit hash, seeds, budgets, requested environment variables, Julia
  invocation and CPU model. These manifests do NOT record Python-package
  versions.
- Everything else about the October run-time package versions is therefore
  NOT independently verifiable from the records; the machine and its
  environment were not changed between the runs and the measurement, but
  that continuity is a statement, not a recorded proof.

## Solver-free use

`paper_stats.py`, `paper_figs.py`, `gen_tracka_tables.py`,
`gen_trackb_tables.py`, `gen_appendix_tables.py`, `gen_arc.py`,
`niche_generator.py`, `kilit_nis_uret.py`, `vallada_to_hlbb.py`,
`kilit_saf_veri_denetimi.py` and `ref2009_cevir.py` run with pandas/numpy
only. `gen_gantt.py`, the README's schedule re-verification command and the
`report` subcommands of `ablation_run.py`/`sensitivity_run.py` import the
method's modules, whose import INITIALIZES an empty Gurobi environment
(`methods.py` calls `env.start()` at module level): gurobipy must be able
to start an environment — the restricted licence bundled with
`pip install gurobipy` suffices and nothing is solved, but a
present-but-invalid licence file blocks even these imports.
`validate_algo.py` needs Julia (it drives the capsule via subprocess).
The feasibility checker (`feasibility.py`) is mode-dependent: its
assignment/sequence checks perform no solve (gurobipy must merely be
installed, because the import chain loads it), but its exact-ATSP
re-routing option builds and solves Gurobi models and therefore needs a
licence. `verify_all.py` re-runs the methods: full chain needs Gurobi,
CP Optimizer, LKH and Julia. See the mode-level table in `MANIFEST.md`.

## Julia package environment

`rolim_capsule/code/Project.toml` + `Manifest.toml` pin the package set the
algorithms use: `StatsBase v0.34.4`, `Hungarian v0.7.0`,
`Distributions v0.25.100` (plus `Random` from the standard library),
resolved under `julia_version = "1.7.0"`. They were generated by the author
on the run machine on 2026-11-11 with `JULIA_PKG_OFFLINE=true` against the
depot the runs used (`julia --project=. -e 'using Pkg;
Pkg.add(["StatsBase","Hungarian","Distributions"]); Pkg.status()'` from
`rolim_capsule/code/`), so the resolved versions are the INSTALLED ones,
not registry upgrades. The original capsule carried no project files; the
same continuity caveat as above applies (the depot was not changed between
the October runs and this measurement, but that is a statement, not a
recorded proof).
