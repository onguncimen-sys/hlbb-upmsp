# Changelog

## v1.0.0 — 2026-11-23

First public release, accompanying the submitted paper. Contents: the HLBB
implementation and its import closure, the locked benchmark runners and
their raw evidence files, the extended Rolim & Nagano (2025) capsule with
documented pre-extension snapshots, the analysis and verification tools,
and the documentation set (`README.md`, `MANIFEST.md`, `ENVIRONMENT.md`,
`INSTANCE_FORMAT.md`, `DATA_DICTIONARY.md`, `DATA_ARCHIVE.md`,
`KNOWN_LIMITATIONS.md`). The companion data record (10.5281/zenodo.24198707) holds the
niche instances and the CP solver logs.
